\# HPC Benchmark - DuckDB, Parquet y CSV



Proyecto experimental orientado al análisis del rendimiento paralelo utilizando DuckDB sobre archivos Apache Parquet y procesamiento de CSV con errores controlados.



\## Objetivo



Evaluar:

\- Tiempo de ejecución

\- Speedup

\- Eficiencia paralela

\- Manejo de errores

\- Impacto del formato de almacenamiento



\## Tecnologías



\- Python

\- DuckDB

\- Apache Parquet

\- Pandas

\- Matplotlib



\## Dataset



NYC Taxi Trip Records:

https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page



\## Estructura



\- `scripts/`: códigos fuente

\- `results/`: resultados experimentales

\- `figures/`: gráficas

\- `docs/`: documentación

\- `data/`: datasets originales
