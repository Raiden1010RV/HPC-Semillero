# Dataset

Los archivos originales Apache Parquet y CSV utilizados en este proyecto no se incluyen en el repositorio debido a su tamaño.

El experimento fue realizado utilizando datasets de NYC Taxi Trips.

Los datos pueden descargarse desde:

https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page

Una vez descargados, los archivos deben ubicarse dentro de esta carpeta (`data/`).
